# Daily Math

Play on desktop or mobile: https://mkefefe.github.io/daily-math/

Playgama Sandbox: https://playgama.ai/play/4syjppe2vyleqz

JavaScript math game with 18,400 questions, adaptive practice, visual hints,
a zoomable whiteboard, calculator and Cloudflare-backed leaderboard.
Optional age-themed challenges use approximate curriculum-inspired difficulty
labels, not IQ or population intelligence comparisons.

Correct: +10/+8/+6/+4 for zero/one/two/three hints. Wrong guess: -5. Skip: -10.
Scores never fall below zero. Hints never request ads.
The Playgama-specific package loads official Bridge v2 before gameplay,
uses Bridge storage, and requests an interstitial on Continue at a natural break.
The GitHub version does not request ads.

Audio asset provenance and font/icon licenses are in assets/.
